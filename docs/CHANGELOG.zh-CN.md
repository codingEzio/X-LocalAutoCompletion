# 更新日志

### 0.5.1 — 2026-09-21

- 使用 codingEzio Marketplace 发布者身份，以便通过已授权的 Microsoft 帐户发布扩展。

### 0.5.0 — 2026-09-20

- README 和设置界面新增七种语言的翻译，并保留 English 作为后备语言。
- 将 Visual Studio Code 记录为受支持的宿主，并验证其支持状态。

### 0.4.1 — 2026-09-20

- 将受限使用的 Google Web Trillion Word Corpus 衍生词表，改为取自经审查、采用 MIT 许可的 ECDICT
  快照中的常用词和考试词汇。
- 使 ECDICT 词汇提取结果可重复，并通过校验和把关。

### 0.4.0 — 2026-09-15

- 产品更名为 X-LocalAutoCompletion。
- 从当前文件全文补全，不再局限于附近几行。
- 始终提供经过排序的离线英文词汇：先列常用词，再列仅用于考试的额外词汇。
- 移除工作区索引、已学习的候选词、固定词汇、补全界面切换、CJK 地区设置，以及实验性原生性能测试后端。

### 0.3.2 — 2026-09-07

- 复制文本前先限制文档读取量；扫描行尾标识符时，不重复扫描长行。
- 使行内建议符合输入文字的大小写，并兼容所选的补全菜单项。

### 0.3.1 — 2026-09-07

- 保留最近接受的 250 条记录，让历史记录已满时仍能学习新的选择。

### 0.3.0 — 2026-09-07

- 新增可选的离线英文词汇，包含标记为 IELTS、TOEFL、GRE 的词汇。

### 0.2.1 — 2026-09-07

- 修复 Command Palette 中四个用户命令的注册项。

### 0.2.0 — 2026-09-03

- 新增工作区本地学习、显式工作区索引，以及原生补全界面的选择功能。

### 0.1.0 — 2026-09-03

- 初版：根据附近文档内容补全单词。
