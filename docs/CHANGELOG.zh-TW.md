# 變更記錄

### 0.5.0 — 2026-09-20

- README 與設定介面新增七種語言的翻譯，並保留 English 作為後備語言。
- 將 Visual Studio Code 記錄為支援主機，並驗證其支援狀態。

### 0.4.1 — 2026-09-20

- 將受限使用的 Google Web Trillion Word Corpus 衍生詞表，改為取自經審查、採 MIT 授權的 ECDICT
  快照之常用詞與考試詞彙。
- 讓 ECDICT 詞彙擷取結果可重現，並以校驗碼把關。

### 0.4.0 — 2026-09-15

- 產品更名為 X-LocalAutoCompletion。
- 從目前檔案全文補全，不再限於附近幾行。
- 一律提供經排序的離線英文詞彙：先列常用詞，再列僅供考試的額外詞彙。
- 移除工作區索引、已學會的候選詞、固定詞彙、補全介面切換、CJK 地區設定，以及實驗性原生效能測試後端。

### 0.3.2 — 2026-09-07

- 複製文字前先限制文件讀取量；掃描行尾識別字時，不重複掃描長行。
- 讓行內建議符合輸入文字的大小寫，並與所選的補全選單項目相容。

### 0.3.1 — 2026-09-07

- 保留最近接受的 250 筆紀錄，讓歷史記錄已滿時仍可學習新的選擇。

### 0.3.0 — 2026-09-07

- 新增可選用的離線英文詞彙，包含標記為 IELTS、TOEFL、GRE 的詞彙。

### 0.2.1 — 2026-09-07

- 修正 Command Palette 中四個使用者指令的註冊項目。

### 0.2.0 — 2026-09-03

- 新增工作區本機學習、明確的工作區索引，以及原生補全介面的選擇功能。

### 0.1.0 — 2026-09-03

- 初版：從附近文件內容補全單字。
