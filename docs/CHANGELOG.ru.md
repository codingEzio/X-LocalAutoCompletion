# История изменений

Русский · [Українська](CHANGELOG.uk.md)

## 0.5.2 — 2026-09-21

- В манифесте VSIX указана публичная доступность Marketplace, чтобы ручная загрузка не оставалась
  приватной.

## 0.5.1 — 2026-09-21

- Используется идентификатор издателя Marketplace codingEzio, чтобы публиковать расширение из
  авторизованной учетной записи Microsoft.

## 0.5.0 — 2026-09-20

- README и настройки расширения получили локализации еще на семи языках; английский сохранен как
  резервный язык.
- В документации Visual Studio Code указан как поддерживаемое хост-приложение; совместимость
  расширения с ним проверена.

## 0.4.1 — 2026-09-20

- Словарь, производный от Google Web Trillion Word Corpus и ограниченный в использовании, заменен
  общеупотребительной и экзаменационной лексикой из проверенного снимка ECDICT, распространяемого по
  лицензии MIT.
- Извлечение данных из ECDICT сделано воспроизводимым; контрольная сумма исходного файла
  проверяется.

## 0.4.0 — 2026-09-15

- Продукт переименован в X-LocalAutoCompletion.
- Поиск дополнений выполняется по всему текущему файлу, а не по окну соседних строк.
- Офлайн-английская лексика с ранжированием предлагается всегда: сначала общеупотребительные слова,
  затем дополнительные экзаменационные слова.
- Удалены индексирование рабочей области, кэш обучения, закрепленные слова, переключение способа
  показа вариантов дополнения, параметры локали CJK и экспериментальный нативный модуль
  бенчмаркинга.

## 0.3.2 — 2026-09-07

- Объем чтения документа ограничен перед копированием текста; идентификаторы в конце строк
  сканируются без повторного просмотра длинных строк.
- Встроенные подсказки остаются совместимыми с регистром введенного текста и выбранным пунктом меню
  дополнений.

## 0.3.1 — 2026-09-07

- Сохраняются 250 последних принятых записей, поэтому даже заполненная история может запоминать
  новые варианты.

## 0.3.0 — 2026-09-07

- Добавлен включаемый пользователем офлайн-словарь английского языка со словами, помеченными для
  IELTS/TOEFL/GRE.

## 0.2.1 — 2026-09-07

- Исправлены пункты Command Palette для четырех пользовательских команд.

## 0.2.0 — 2026-09-03

- Добавлены обучение отдельно для каждой рабочей области, явное индексирование рабочей области и
  выбор интерфейса нативного автодополнения.

## 0.1.0 — 2026-09-03

- Первоначальная версия с дополнением слов по соседнему контексту документа.
