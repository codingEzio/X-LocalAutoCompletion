# 변경 사항

## 0.5.0 — 2026-09-20

- English를 대체 언어(fallback)로 유지하고, 7개 언어 번역을 새로 추가했습니다.
- Visual Studio Code를 지원 호스트로 README에 기록하고, 지원 호스트임을 검증했습니다.

## 0.4.1 — 2026-09-20

- 재배포가 제한된 Google Web Trillion Word Corpus 파생 어휘 목록을 검토된 MIT 라이선스 ECDICT
  스냅샷의 일반 어휘 및 시험 어휘로 교체했습니다.
- ECDICT 추출을 결정적으로 만들고 체크섬으로 검증하도록 했습니다.

## 0.4.0 — 2026-09-15

- 제품 이름을 X-LocalAutoCompletion으로 변경했습니다.
- 가까운 줄 범위가 아닌 현재 파일 전체에서 단어를 완성합니다.
- 순위가 매겨진 오프라인 영어를 항상 포함합니다. 일반 어휘를 먼저, 시험 전용 추가 어휘를 다음에
  제시합니다.
- 워크스페이스 색인, 학습된 선택 기록, 고정 단어, 완성 UI 전환, CJK 로캘 설정 및 실험용 네이티브
  벤치마크 백엔드를 제거했습니다.

## 0.3.2 — 2026-09-07

- 텍스트를 복사하기 전에 문서 읽기 크기를 제한하고, 긴 줄을 다시 훑지 않으면서 끝부분의 식별자를
  검색합니다.
- 인라인 제안이 입력된 대소문자 형식 및 선택한 완성 메뉴 항목과 호환되도록 했습니다.

## 0.3.1 — 2026-09-07

- 기록이 가득 찬 뒤에도 새 선택을 학습할 수 있도록 가장 최근에 수락된 기록 250개를 유지합니다.

## 0.3.0 — 2026-09-07

- 사용자가 선택해 켤 수 있는 오프라인 영어 어휘를 추가했습니다. IELTS/TOEFL/GRE 태그가 붙은 단어가
  포함됩니다.

## 0.2.1 — 2026-09-07

- 사용자 명령 네 가지에 대한 Command Palette 기여 항목을 수정했습니다.

## 0.2.0 — 2026-09-03

- 워크스페이스 단위 학습, 명시적 워크스페이스 색인 및 네이티브 완성 UI 선택을 추가했습니다.

## 0.1.0 — 2026-09-03

- 현재 문서의 가까운 범위에서 단어를 완성하는 초기 버전입니다.
