# 変更履歴

## 0.5.0 — 2026-09-20

- English をフォールバックとして維持し、新たに 7 言語の翻訳を追加しました。
- Visual Studio Code をサポート対象ホストとして README
  に記録し、対応ホストであることを検証しました。

## 0.4.1 — 2026-09-20

- 再配布が制限される Google Web Trillion Word Corpus の派生語彙リストを、確認済みの MIT ライセンス
  ECDICT スナップショットに含まれる一般語彙と試験向け語彙に置き換えました。
- ECDICT の抽出を決定的にし、チェックサムで検証するようにしました。

## 0.4.0 — 2026-09-15

- 製品名を X-LocalAutoCompletion に変更しました。
- 近くの行範囲ではなく、現在のファイル全体から単語を補完します。
- 順位付けされたオフライン英語語彙を常に候補に含めます。一般語を先に、試験専用の追加語彙を後に表示します。
- ワークスペースのインデックス作成、学習済み選択肢、単語の固定、補完表示方式の切り替え、CJK
  ロケール設定、実験的なネイティブ・ベンチマーク・バックエンドを削除しました。

## 0.3.2 — 2026-09-07

- テキストをコピーする前にドキュメントの読み取り量に上限を設け、長い行を再走査せずに末尾の識別子を検索します。
- インライン候補が入力時の大文字・小文字と、選択中の補完メニュー項目に対応するようにしました。

## 0.3.1 — 2026-09-07

- 履歴が上限に達しても新しい選択を学習できるよう、最近受け入れた記録を 250 件保持します。

## 0.3.0 — 2026-09-07

- IELTS/TOEFL/GRE
  のタグ付き単語を含む、利用者が選択して有効にできるオフライン英語語彙を追加しました。

## 0.2.1 — 2026-09-07

- 4 つのユーザー向けコマンドに対する Command Palette の登録を修正しました。

## 0.2.0 — 2026-09-03

- ワークスペース内での学習、明示的なワークスペースのインデックス作成、ネイティブ補完表示面の選択を追加しました。

## 0.1.0 — 2026-09-03

- ドキュメント内の近くにある単語を補完する初期版です。
