# Історія змін

Українська · [Русский](CHANGELOG.ru.md)

## 0.5.0 — 2026-09-20

- README та налаштування розширення додатково локалізовано ще сімома мовами; англійську збережено як
  резервну мову.
- У документації Visual Studio Code зазначено як підтримувану програму-хост; сумісність розширення з
  ним перевірено.

## 0.4.1 — 2026-09-20

- Словник, похідний від Google Web Trillion Word Corpus та обмежений у використанні, замінено
  загальновживаною й екзаменаційною лексикою з перевіреного знімка ECDICT, що поширюється за
  ліцензією MIT.
- Вилучення даних з ECDICT зроблено відтворюваним; контрольну суму вихідного файла перевіряють.

## 0.4.0 — 2026-09-15

- Продукт перейменовано на X-LocalAutoCompletion.
- Доповнення шукаються в усьому поточному файлі, а не у вікні сусідніх рядків.
- Офлайн-англійська лексика з ранжуванням пропонується завжди: спочатку загальновживані слова, далі
  додаткові екзаменаційні слова.
- Вилучено індексування робочого простору, кеш навчання, закріплені слова, перемикання способу
  показу варіантів доповнення, параметри локалі CJK та експериментальний нативний модуль
  бенчмаркінгу.

## 0.3.2 — 2026-09-07

- Обсяг читання документа обмежено перед копіюванням тексту; ідентифікатори в кінці рядків
  скануються без повторного перегляду довгих рядків.
- Вбудовані підказки залишаються сумісними з регістром введеного тексту та вибраним пунктом меню
  доповнень.

## 0.3.1 — 2026-09-07

- Зберігаються 250 останніх прийнятих записів, тому навіть заповнена історія може запам'ятовувати
  нові варіанти.

## 0.3.0 — 2026-09-07

- Додано словник англійської мови, який користувач може ввімкнути офлайн; до слів додано позначки
  IELTS/TOEFL/GRE.

## 0.2.1 — 2026-09-07

- Виправлено пункти Command Palette для чотирьох користувацьких команд.

## 0.2.0 — 2026-09-03

- Додано навчання окремо для кожного робочого простору, явне індексування робочого простору та вибір
  інтерфейсу нативного автодоповнення.

## 0.1.0 — 2026-09-03

- Початкова версія з доповненням слів за сусіднім контекстом документа.
